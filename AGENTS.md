# Agentic OS Agent Rules

This project is under END_PRODUCT_RECONSTRUCTION_POLICY_V1.

Agent panes must be honest:
- usable agents get input → Send/Run → output;
- unusable agents show the exact missing integration;
- no fake command surfaces.

The user-facing product target is a functional cockpit, not a monitoring baseline.

First priority:
The Claude Code Agent must be usable directly from Home. FCC is only its model gateway and raw FCC completions are diagnostic, not agent execution.
